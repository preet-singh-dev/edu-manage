# Student Management System

A web application to manage student records, built with PHP and MySQL. It supports secure login, adding, viewing, updating and deleting student data, and searching records quickly.

## Features

- Login system for authorized users
- Add new student records
- View all students in a table
- Edit and update student details
- Delete student records
- Search students
- Responsive interface built with Bootstrap

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL

## Run Locally

1. Install [XAMPP](https://www.apachefriends.org/) (or any PHP + MySQL setup).
2. Clone the repository into the `htdocs` folder:
   ```bash
   git clone https://github.com/preet-singh-dev/<repository-name>.git
   ```
3. Start **Apache** and **MySQL** from the XAMPP control panel.
4. Open phpMyAdmin, create a new database and import the `.sql` file from this project.
5. Update the database connection details (host, username, password, database name) in the project's connection file.
6. Open `http://localhost/<repository-name>/` in your browser.
